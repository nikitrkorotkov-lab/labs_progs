## Архитектура

Проект построен по принципу **разделения ответственности**:

- **Services/** — независимые модули с бизнес-логикой (чистый C#, без UI)
- **Views/** — UI компоненты (UserControl) для каждой лабораторной
- **Form1** — главная форма-контейнер с TabControl
- **DoubleBufferedPanel** — кастомная панель с двойной буферизацией для устранения мерцания

Каждая лабораторная работа изолирована и может развиваться независимо.

### Технические особенности

- **Двойная буферизация** — устранено мерцание при рисовании в Lab3
- **C# 8.0** — использование switch expressions и using declarations
- **Многопоточность** — параллельная обработка массивов в Lab2, асинхронная отрисовка фракталов в Lab3
- **Flood Fill** — алгоритм заливки области в Lab3
- **Фракталы** — дерево Пифагора и салфетка Серпинского с градиентной заливкой
- **Ряды Фурье** — рекурсивное вычисление и визуализация разложения сигналов с анимацией

## Lab2 — Обработка массивов с многопоточностью

### Описание задачи

Обработка целочисленного массива в 3 шага:

1. **Удалить элементы**, у которых все цифры одинаковы (11, 222, -33, 5 и т.д.)
2. **Вставить число k** перед каждым элементом, содержащим цифру 1
3. **Переставить местами** первые 3 и последние 3 элемента

**Пример:**
```
Вход:  [11, 12, 13, 21, 22, 33, 14, 15, 16]
k = 99

Шаг 1 (удалить 11, 22, 33): [12, 13, 21, 14, 15, 16]
Шаг 2 (вставить 99 перед 12, 13, 21, 14, 15, 16): [99, 12, 99, 13, 99, 21, 99, 14, 99, 15, 99, 16]
Шаг 3 (переставить): [99, 15, 99, 13, 99, 21, 99, 14, 99, 12, 99, 16]
                      └─────┬─────┘              └─────┬─────┘
                       последние 3              первые 3
```

### Многопоточность

| Шаг | Что делается | Потоки |
|-----|-------------|--------|
| 1 | Удаление элементов с одинаковыми цифрами | 2 потока параллельно (левая и правая половины массива) |
| 2 | Вставка k перед элементами с цифрой 1 | 1 поток |
| 3 | Перестановка первых 3 и последних 3 | 1 поток |

**Замер времени:** UI показывает время выполнения для обоих режимов (с/без потоков).

**Код сервиса:** `Services/Lab2/Lab2Service.cs`  
**Интерфейс:** `Views/Lab2Control.cs`

## Lab3 — Графический редактор с фракталами и сигналами Фурье

### Описание

Lab3 состоит из трёх частей, организованных во внутренние вкладки:

**Часть 1: Графический редактор**
- Полноценный растровый редактор с инструментами рисования
- Создание/открытие/сохранение изображений (PNG, BMP, JPEG)
- Настройка параметров (цвет, толщина, тип линии, заливка)
- Изменение цвета фона с сохранением рисунка

**Часть 2: Фракталы**
- Дерево Пифагора с рекурсивным построением (глубина 1-20, по умолчанию 8)

- Градиентная заливка на каждом уровне рекурсии
- Асинхронная отрисовка без блокировки UI

**Часть 2: Ряд Фурье (Вариант 13)**
- Рекурсивное вычисление суммы ряда Фурье
- Визуализация разложения сигналов с прямоугольной огибающей

### Часть 2: Фракталы

#### Дерево Пифагора

**Описание:**
Рекурсивный фрактал, построенный на основе квадратов и равнобедренных прямоугольных треугольников.

**Алгоритм:**
1. Рисуется квадрат на заданном горизонтальном основании
2. Квадрат строится вверх (перпендикуляр к основанию)
3. На верхней стороне квадрата строится равнобедренный прямоугольный треугольник (45°)
4. На катетах треугольника рекурсивно строятся два дочерних дерева
5. Процесс повторяется до достижения заданной глубины

**Особенности:**
- Градиентная заливка: от коричневого (139,90,43) к зелёному (34,139,34)
- Глубина рекурсии: 1-20 уровней (по умолчанию 8)
- Начальный размер ствола: 14% от ширины окна
- Асинхронная отрисовка с Task.Run
- Автоматическая перерисовка при изменении N

#### Салфетка Серпинского

**Описание:**
Фрактальный треугольник, построенный методом рекурсивного деления.

**Алгоритм:**
1. Берётся равносторонний треугольник
2. Закрашивается текущим цветом (зависит от глубины)
3. Находятся середины всех сторон
4. Рекурсивно рисуются три треугольника в углах
5. Центральный треугольник остаётся цвета родителя — создаётся эффект "дырки"

**Особенности:**
- Градиентная заливка на каждом уровне: от синего (20,80,200) к фиолетовому (200,40,220)
- Глубина рекурсии: 0-12 уровней (по умолчанию 6)
- Автоматическое масштабирование под размер окна
- Асинхронная отрисовка

### Часть 2: Сигналы Фурье (Вариант 13)

Отдельное окно с визуализацией разложения в ряд Фурье.

#### Реализация рекурсивного вычисления

**Рекуррентный вызов (Вариант 13):**
```csharp
public double FourierSumRecursive(SignalType type, int n, int maxN, double x)
{
    if (n >= maxN) return 0;  // база рекурсии
    int k = GetHarmonicIndex(type, n);
    return HarmonicValue(type, k, x) + FourierSumRecursive(type, n + 1, maxN, x);
}
```

#### Типы сигналов

1. **Прямоугольная огибающая**
   - Формула: `f(x) = (4/π) · Σ [sin(k·x) / k]`, где k = 1, 3, 5, 7...

2. **Треугольная огибающая**
   - Формула: `f(x) = (8/π²) · Σ [(-1)^((k-1)/2) · sin(k·x) / k²]`, где k = 1, 3, 5, 7...

3. **Пилообразная огибающая**
   - Формула: `f(x) = (2/π) · Σ [(-1)^(k+1) · sin(k·x) / k]`, где k = 1, 2, 3, 4...

#### Возможности

- Выбор типа сигнала (прямоугольная/треугольная/пилообразная)
- Настройка количества гармоник (от 1 до 50)
- «Живая» анимация — сигнал движется в реальном времени (30 FPS)
- Отображение отдельных гармоник (цветные полупрозрачные линии)
- Суммарный сигнал (жёлтая линия) вычисляется рекурсивно
- **Двойная буферизация** — плавная анимация без мерцания
- Кнопка паузы/пуска анимации
- Тёмная тема интерфейса с сеткой и осями координат

## Lab4 — DLL + Парсинг лог-журнала обработчиков исключений

### Описание

Lab4 реализует парсинг лог-журналов с использованием регулярных выражений и динамической библиотеки (DLL). Включает анализ исключений, поиск сигнатур, асинхронную обработку и визуализацию результатов.

### Основные возможности

**Пункт 1: Выделение сигнатур**
- Выбор сигнатуры из ComboBox (form, System, Exception и др.)
- Автоматическое выделение всех вхождений выбранной сигнатуры цветом
- Динамическое обновление при смене сигнатуры

**Пункт 2: Поиск при вводе текста**
- Автоматический поиск всех сигнатур при ручном вводе текста
- Последовательное выделение всех найденных вхождений
- Работает без загрузки файла

**Пункт 3: Анализ форм с исключениями**
- Поиск всех упоминаний форм (Form1, Form2, Form3 и т.д.) в лог-журнале
- Подсчёт количества появлений каждой формы
- Цветовое выделение найденных форм (оранжево-красный)
- Вывод статистики в отдельное окно

**Пункт 4: Парсинг по варианту 13**
- Поиск всех вхождений словоформ "form*" в заданном диапазоне дат
- Выбор диапазона дат через DateTimePicker (от <дд.мм.гггг> до <дд.мм.гггг>)
- Автоматическое добавление ФИО "Коротков Н.Д." красным цветом после каждого найденного вхождения
- Подсветка найденных вхождений тёмно-синим цветом
- Вывод количества найденных вхождений

**Пункт 5: Парсинг через DLL с замером времени**
- Загрузка одного или нескольких лог-журналов
- Синхронный парсинг с измерением времени для каждого файла
- Использование класса FormParser из DLL LogParserDLL
- Вывод результатов: количество вхождений и время обработки
- Суммарное время обработки всех файлов

**Пункт 6: Асинхронный парсинг с графиками**
- Асинхронная обработка нескольких лог-журналов параллельно
- Сравнение времени выполнения синхронного и асинхронного режимов
- Автоматическое открытие формы с графиками после завершения
- График зависимости времени парсинга от размера журнала
- Две линии: синхронный (синий) и асинхронный (красный) режимы
- Тестирование на разных размерах (x1, x2, x3, x5, x8 копий текста)

**DLL-проект: LogParserDLL**

  - Регулярное выражение для поиска "form*" (без учёта регистра)
